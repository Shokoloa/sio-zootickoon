# ZooTickoon - Parc animalier de Val-Sorin

Site public du parc et application de tickets d'incident. Projet BTS SIO, premier semestre.

## Ouvrir

1. Laragon démarre ; le dossier est dans `C:\laragon\www\zootickoon`
2. http://zootickoon.test

## Données

Le kit du parc est dans `data/` (CSV, JSON, XML, SQL, visuels, gabarits).
Comptes de test : `data/README.md`.
La base s'importe à la mission 4 : les commandes sont dans `data/README.md`.

⚠️ Les fichiers `data/images/*.svg` de ce dépôt sont des visuels de remplacement
générés en attendant l'import du vrai kit `zootickoon-data/` du dépôt de cours
(dossiers `json/`, `xml/`, `sql/`, `gabarits/` et images définitives à copier
par-dessus ce dossier `data/`).
